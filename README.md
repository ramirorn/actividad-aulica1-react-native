# SmartSpend 💸

**SmartSpend** es una aplicación móvil desarrollada con React Native y Expo, diseñada para facilitar el seguimiento y control de gastos personales de forma sencilla e intuitiva.

## 📝 Justificación del Proyecto

La gestión financiera personal suele ser un desafío debido a la complejidad de muchas herramientas actuales. **SmartSpend** nace como una solución rápida e intuitiva que permite a los usuarios registrar sus gastos diarios al instante, visualizarlos en un panel principal limpio y obtener resúmenes automáticos agrupados por categorías. Al enfocarse en la usabilidad, los 3 estados fundamentales de UI (carga, vacío y contenido) y prescindir de flujos abrumadores, la aplicación resuelve la necesidad de llevar un control de presupuesto sólido con tan solo un par de toques en la pantalla del celular.

## 🚀 Requisitos Previos

- [Node.js](https://nodejs.org/) (versión LTS recomendada).
- Aplicación [Expo Go](https://expo.dev/client) instalada en tu dispositivo móvil (Android / iOS).

## 🛠️ Instalación y Ejecución

1. **Ubicarse en el directorio de la aplicación:**
   Abre una terminal y asegúrate de estar dentro de la carpeta `smart-spend`:
   ```bash
   cd smart-spend
   ```

2. **Instalar las dependencias:**
   Ejecuta el siguiente comando para descargar todos los paquetes necesarios:
   ```bash
   npm install
   ```

3. **Iniciar el servidor de desarrollo de Expo:**
   Una vez instaladas las dependencias, levanta el entorno de desarrollo con:
   ```bash
   npx expo start
   ```

4. **Probar la aplicación:**
   - Abre la aplicación **Expo Go** en tu celular.
   - Escanea el **código QR** que aparece en la terminal.
   - Automáticamente se construirá el bundle y la aplicación se abrirá en tu dispositivo lista para usar.
   
   *(Opcional: Si cuentas con el entorno configurado en tu PC, puedes presionar `a` en la terminal para abrir el emulador de Android).*
